# timer_loghome_membership

原木通行证自动续费 SCF 定时函数。

## 行为

- 扫描已经到期且开启 `auto_renew` 的活动订阅。
- 在事务中锁定订阅和用户原木账户。
- 余额充足时扣除订阅记录中的 `renewal_cost_log` 续费价格快照，并生成下一周期记录；旧数据会回退使用 `cost_log`。
- 月付续费成功时赠送 100/200 红石；年付会员按 `next_redstone_grant_at` 每月赠送 100/200 红石。
- 红石发放写入带唯一业务键的 `redstone_transactions`，函数重试不会重复发放。
- 未开通有效通行证的普通用户每个自然月赠送 6 红石，按批次补发并使用月度业务键防止重复到账。
- 通行证及普通用户月度赠送红石按独立批次记录，自到账日起 3 个月有效；定时函数会清理到期批次并生成过期流水。
- 原木兑换的红石没有到期时间；业务消费按“最早到期优先、永久余额最后”的顺序扣减。
- 余额不足或价格异常时关闭自动续费、记录失败原因，并发送站内通知。
- `renewal_parent_id` 唯一约束保证同一周期不会被重复续费。
- 最后将已到期且未开启自动续费的记录标记为 `expired`。

## 配置

推荐在 SCF 环境变量中配置：

- `DB_HOST`
- `DB_PORT`，默认 `3306`
- `DB_USER`
- `DB_PASSWORD`
- `DB_NAME`

也可以复制 `config.example.js` 为不会提交到 Git 的 `config.js`。

## 部署

入口为 `index.main_handler`。建议配置每 10 分钟执行一次的定时触发器；函数具备事务和幂等保护，可以安全重试。
