# Chinese PDF font

`SourceHanSansSC-Regular.ttf` is an unchanged copy of the font already used by
`loghome-scf-subtasks/loghome-novel-export-vip/SourceHanSansSC-Regular.ttf`.
It is kept inside the backend so deployments do not depend on a sibling service.

The font's embedded name table identifies it as **Source Han Sans SC Regular**,
PostScript name `SourceHanSansSC-Regular`, version **2.004**. Its copyright notice
is “© 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.”
The embedded license specifies the **SIL Open Font License 1.1**.

Upstream project: https://github.com/adobe-fonts/source-han-sans
Upstream license: https://github.com/adobe-fonts/source-han-sans/blob/release/LICENSE.txt

The applicable font copyright notice and full OFL text are included in `OFL.txt`.
PDFKit embeds only the glyphs used by a generated PDF.
