# Address region data

Bundled from [modood/Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China), `dist/pca-code.json`, retrieved 2026-10-01.

The upstream dataset contains 31 mainland province-level regions and is based on the 2023 statistics release (cutoff 2023-06-30). It is an offline snapshot, not a live administrative directory. Replace this file to update the options. No remote request is made when the address picker opens.

Source: https://raw.githubusercontent.com/modood/Administrative-divisions-of-China/master/dist/pca-code.json
