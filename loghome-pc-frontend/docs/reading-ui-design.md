# PC 阅读区 UI 优化

## 设计依据

- [Taste Skill](https://github.com/Leonxlnx/taste-skill/blob/main/skills/taste-skill/SKILL.md)
- [Redesign Skill](https://github.com/Leonxlnx/taste-skill/blob/main/skills/redesign-skill/SKILL.md)
- 模式：保留品牌与信息架构的改版，沿用 Nuxt 2、Vue 2、Element UI、原生 CSS。
- 参数：DESIGN_VARIANCE 5、MOTION_INTENSITY 3、VISUAL_DENSITY 7。
- 阅读区是日常产品界面，使用 Skill 的重设计、排版、配色与可访问性原则；不套用营销页的巨型标题、滚动叙事或装饰性图片。

## 现状与调整

| 现状 | 调整 |
| --- | --- |
| 书库卡片中再嵌套大量作品卡片边框 | 区块保留容器，作品以封面、文字和留白分组 |
| 作者、状态、更新等信息大量使用 9–11px 浅色文字 | 书名 14–15px，辅助文字通常 12–13px，提高对比度 |
| 桌面主内容较窄，三列榜单容易截断长书名 | 页面最大宽度 1440px，侧栏 300px，榜单按宽度使用两列/三列 |
| 不同页的木色、橙色、绿色交互主色不一致 | 木色主操作统一，语义性的作品徽章、树场插画与阅读背景保留 |
| 详情页的封面、标题、统计信息缺少一致排布 | 小说、漫画、世界设定统一为左封面与右信息区 |
| 目录逐行边框、书摘嵌套容器偏重 | 分卷目录用柔和底色，章节用间距与选中状态；书摘去掉内层边框 |
| 手机宽度的全站导航会折行、正文工具被挤压 | 阅读路由增加明确的窄屏导航和工具布局 |
| 页脚链接颜色适配深色页脚，浅色主题难辨认 | 阅读区页脚使用木色链接，其他区域保留原色 |

## 样式边界

- `assets/css/reading-theme.css` 维护阅读路由的语义色、页面间距、详情页与工具外观。
- `layouts/default.vue` 的 `reading-layout` 只覆盖 `/read`、`/novel`、`/article`、`/manga`、`/world`、`/tags`、`/tag`。
- 书卡、榜单、书架、专题、目录、书摘保留独立组件样式，使用同一组变量及独立回退值。
- 附加到 body 的抽屉与对话框通过 `reading-drawer` / `reading-dialog` 携带自己的变量，避免影响写作区或社区的弹窗。
- 圆角规则：区块 12px、交互控件 6px、封面 4px。
- 灰色站点背景按用户要求保留；正文阅读主题与漫画阅读背景继续由用户已有偏好决定，不由系统暗色偏好覆盖。
- 动效只用于悬停和按下反馈，减少动态效果偏好下禁用。
- 增加跳到内容的键盘入口，阅读子页面保持导航选中状态。

## 保留项

- 已删除的书库顶部标题与工具栏不恢复。
- 路由、内容、分页链接、SSR 数据获取、SEO head/canonical/OG/JSON-LD、隐私页 noindex 策略不变。
- 收藏、进度、评论、书摘、听书、设置、奖励、AI 等请求与账户生命周期逻辑不变。
- 不新增依赖，不更换框架，不生成虚构作品、统计数字或装饰性封面。
- 按用户要求暂停账户功能联调。仅查看本地预览的布局、编译反馈及代码差异，不提交评论、点赞、兑换或其他测试写入。
