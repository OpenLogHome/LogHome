# PC 在线听书

登录后，播放器通过原木后端 `POST /tts/session` 获取与用户绑定的 TTS token 和
音色映射。正文随后直接发送至 `https://tts.codesocean.top/v1/audio/speech`，使用用户
token、服务端解析的 `voice_id` 和默认模型；浏览器不接触管理员 key。

## 播放体验

- 四个免费音色：温润君子、阳光少年、青春女神、软糯萝莉。首次默认温润君子。
- 记住音色、语速和跟随正文偏好，打开入口自动准备并播放。浏览器阻止自动播放时，
  显示提示并保留准备好的音频，点击播放即可继续。
- 同一本书的普通入口复用当前队列、段落和实际音频时间；明确选择段落才跳转。
- 正文按句界分成约 300 字的音频段，预缓冲当前段的下一块及之后三个段落的首块。
  接近章节末尾时预读下一章并缓冲其开头。
- 音频 Blob 仅在内存缓存，按用户、音色和文本隔离，最多 24 项、32 MiB；关闭时释放。
  语速由浏览器调整，无需重新合成。
- 书籍封面用于播放器图片、模糊背景和系统媒体信息。播放器固定在窗口底部，
  自身不滚动，也不捕获音量键。
- 本机仅保存偏好和听书位置元数据，不保存 token、正文或音频。登录凭证刷新会验证
  用户身份并保留同用户的播放位置；退出或切换用户会停止旧队列。
- 草稿在线听书预览会将正文发送到 TTS；使用独立队列，不写公开阅读历史和进度。

## 部署和验证

前端和后端 `/tts/session` 需一并部署。TTS 的 OPTIONS 预检和实际响应须允许
PC 域名跨域访问，允许 `POST`、`Authorization` 和 `Content-Type` 请求头。
后端认证、密钥加密和音色映射见 `../../loghome-backend/docs/tts.md`。

```sh
npm run test:reader-audio
node tests/reader-preview.cjs
node tests/reader-runtime.cjs
npm run build
```

回归使用虚构用户和模拟音频，覆盖队列续播、预缓冲、账号隔离、凭证吊销重试、
播放权限拒绝、缓存释放、草稿预览和本机位置恢复，不会向真实用户分配密钥。
真实服务联调需登录后检查四个音色、长章连续播放、入口重开和系统媒体封面。
