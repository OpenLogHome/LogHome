# 原生 PC 写作迁移

## 基线与差异（2026-10-10）

基于当前工作区源码，移动端以 `chapterEditorNew.vue` 为准，不能以旧设计说明的第一阶段范围代替实际功能。

| 能力 | 移动端 | 原 PC | 迁移方式 |
| --- | --- | --- | --- |
| 编辑内核 | Tiptap / ProseMirror | iframe 指向旧编辑页 | PC 直接实例化同版本 Tiptap |
| 目录 | 搜索、分卷、排序、状态、锁、索引 | 内嵌移动页 | 常驻紧凑目录与键盘操作 |

| 发布 | 预览、草稿、定时、校对、作品可见性 | 内嵌移动流程 | 原生发布面板、revision 校验 |

## 实施顺序

1. 建立 API、兼容文档与账号隔离的备份层；实现安全保存、编辑锁与重连。
2. 替换 `/write/edit/:id` 为原生工作台，保留路由和原生 ReaderPreview。
3. 接入协作、历史、发布、AI、世界词条与漫画。
4. 补齐管理与运营工具、作品类型入口。
5. 自动化验证文档往返、会话冲突、流式结果、Vue 模板与构建；浏览器检查桌面布局和关键流程。

## 桌面交互约束

- 顶栏 56px、左侧目录约 264px、右侧工具约 340px；正文可读行宽，工具面板可收起，专注模式隐藏两翼。
- 可见状态、加载／空／错误／重试、键盘焦点、快捷键提示；所有危险操作明确确认。
- 不通过 iframe、跨站令牌或移动弹窗承载写作功能。
- 不改变阅读端 legacy content；沿用 paragraph legacyId，避免评论锚点失效。
- CRDT 文档初次同步后再创建编辑器；不把本机快照当作共享文档种子。
- 发布前等待协作确认并创建检查点；`collab_revision` 不匹配时要求重新检查。
- 本机数据按账号隔离；上传、切章、恢复、退出时保留未同步内容。

## 验收

保存与发布是两种操作。未发布修改不能意外进入读者正文。拒绝锁、网络失败、离线、旧版本冲突、协作模式切换都不能静默覆盖云端。测试不得写入真实作品或向真实用户发送邀请。

桌面交互没有逐个复制移动端抽屉／按钮：常用编辑操作集中到正文工具栏，管理能力进入右侧面板。字体使用浏览器 FontFace 和 IndexedDB；纯色主题采用适合桌面工作的浅色、纸张、深色。背景皮肤与通行证授权仍来自服务端。作品导出直接生成本机可下载的完整 JSON，避免把后台导出任务返回的 `success` 当成文件。

## 数据兼容与保护

- Tiptap 固定为移动端同版本 2.27.2，Hocuspocus 4.5.0，Yjs 13.6.27；没有引入阅读端无法保存的富文本结构。
- 保存只更新写作稿，发布才更新读者稿。正文 JSON 无法解析时禁止编辑；历史恢复也校验格式。
- 重复段落 ID 只修复重复项，保留已有锚点；不会为解决单个重复 ID 而重编号整篇文章。
- 实时协作等待服务端种子同步，之后创建编辑器；本机离线数据通过账号隔离的 Yjs IndexedDB 合并，不先灌入共享正文。
- Hocuspocus 文档 CLOSE 与底层 WebSocket 状态分开处理；重新检查协作模式／权限后恢复连接，权限被撤销则只读。
- 发布前等待所有更新确认并创建检查点，传入 `collab_revision`；漫画传入 `expected_manga_revision`。
- 本次没有修改后端／移动端协议，也没有向真实账号发邀请、写作品、发布章节或部署服务。工作区原有阅读迁移与其他修改保留。

### 开发环境 SSR 修复

打开写作曾返回 HTTP 500：路由静态导入工作台，导致 Nuxt 服务端执行 Yjs 依赖中的浏览器版 `lib0/webcrypto.js`，在没有全局 `crypto` 的 Node 环境报错。`<client-only>` 只能阻止渲染，不能阻止静态导入的执行。路由现通过 `process.client` 仅在浏览器中异步加载工作台，服务端保留加载提示。

修复前先用回归测试复现了服务端加载编辑器依赖；修复后该测试通过。已有 `localhost:3000` 开发服务热更新后，`/write/edit/7` 从 500 恢复为 200；上述 16 组浏览器模拟流程在该开发服务上再次全部通过，页面错误为零。阅读预览回归也再次通过。这次验证覆盖实际开发环境，不仅依赖提供全局 `crypto` 的新版 Node 生产构建结果。

浏览器测试需要 Playwright 与 Chromium，可通过 `WRITER_PLAYWRIGHT_MODULE` 指定已有 Playwright 包路径，通过 `WRITER_TEST_URL` 指定运行中的 PC 服务（默认 `http://127.0.0.1:3117`）。协作测试复用 `loghome-ai-backend` 已安装的 Hocuspocus 服务端依赖，在本机 3118 端口启动一次性测试服务。

当前 Nuxt 2 / Webpack 4 在新版 Node 上构建需设置 `NODE_OPTIONS=--openssl-legacy-provider`。`WRITER_BUILD_DIR` 可指定隔离构建目录，避免和已有开发服务器竞争 `.nuxt`。AI HTTP／WebSocket 地址分别由 `WRITER_AI_URL`、`WRITER_WS_URL` 配置；默认与移动端一致。

截图与构建日志保存在仓库根目录 `_tmp/writer-migration/`。模拟测试不能替代上线环境中的鉴权、会员、付费 AI 与文件服务联调；这些入口使用现有服务契约，未在真实账号上执行有副作用的验证。

## Notion 风格视觉重构（2026-10-10）

参考 [StyleKit Notion 风格](https://www.stylekit.top/zh/styles/notion-style) 及其 Showcase，迁移内容优先、平铺界面、轻微颜色反馈与系统字体等原则。保留顶栏、左侧目录、中间编辑器、右侧工具面板及工具轨道的结构、宽度与功能。

- 浅色使用白色正文区、`#f7f6f3` 侧栏、`#37352f` 主文字、`#efedea` 悬停及 `#e3e1db` 选中背景。主要动作使用深灰实色；蓝、绿、黄、红只承担聚焦和信息状态。
- 移除正文纸张卡片的边框、圆角与阴影；32px 标题建立层级，正文保留可调字号、行距、行宽与字体。新用户默认系统无衬线字体，已有偏好不覆盖，背景皮肤下仍提供纯色正文底层。
- 按钮与字段统一 4px 圆角，弹窗 6px；交互采用 150ms 颜色／透明度反馈。目录管理菜单支持悬停、键盘聚焦及触屏可见，不引入无法操作的拖拽装饰。
- 深色与纸张主题覆盖相同语义 tokens；发布、创建、历史、AI 建议、版本冲突、漫画预览、确认框、目录菜单与提示消息显式接收主题，避免 append-to-body 后丢失主题。阅读预览仍使用阅读模块自己的样式。
- 降低重阴影与装饰，保留焦点轮廓、禁用反馈、选中语义及减少动效设置。基础文字、辅助文字（包括选中行）、主要按钮和状态提示在三种主题中的设计色值对比度均达到 4.5:1；浅色选中行辅助文字最低约 4.53:1。

验证沿用 16 项写作运行时回归与阅读预览回归；浏览器模拟覆盖原有 16 组功能流程，额外检查深色控件、深色发布弹窗、新建弹窗、纸张、专注及 900px 窗口。视觉截图单独保存在 `_tmp/writer-notion/`，可通过 `WRITER_SCREENSHOT_DIR` 指定输出位置。

## 工作台间距与工具交互完善（2026-10-10）

写作路由固定在当前视口内，工作台改用父容器高度。目录、正文、工具内容和工具轨道分别滚动；面板标题与编辑器状态栏保持可见，离开写作路由后解除页面滚动锁。900px 窗口的工具覆盖层从工作区顶部开始，避免重复计算顶栏高度。

空白工作区明确设置图标、标题、说明与创建按钮之间的间距。目录管理按钮固定为 28×28px，保留右侧 6px 空间与键盘／触屏入口，长标题不会挤压菜单按钮。

新增 `WriterPanel` 与 `WriterEmptyState` 共用面板标题、关闭、刷新、加载、错误重试和空状态。历史／备份使用版本列表；索引用进度与状态表达服务数据；统计为三列指标及局部横向滚动表格；日历支持日期聚焦；协作者权限使用可展开列表；作品设置分组展示资料、开关、封面与标签；偏好显示滑块数值与快捷键。AI 助手增加构思入口，固定输入区；协作讨论沿用统一面板。关闭面板后焦点返回操作入口。

Vue 2 的部分插槽根节点缺少父组件样式标记，因此工具与助手内部样式使用工作台祖先限定，保证统计／日历网格、协作者资料等插槽内容获得一致布局，同时保持其他页面的样式隔离。AI 建议弹窗继续保留自身作用域样式与主题。

加载请求通过序号隔离，旧请求不能覆盖当前章节的工具内容、错误或加载状态。作品资料在内部刷新和父级信息更新时保留未保存输入；主动刷新有放弃修改确认；保存后资料与按钮状态跟随作品信息更新。纠错原文按后端 `paragraph_text` 字段显示。

新增 `npm run test:writer:ui`，通过模拟 API 检查 116 章目录、菜单尺寸与边距、13 个工具入口、固定面板标题、关闭后焦点恢复、设置修改／保存、失败重试、同一面板章节切换时的旧请求、4 种窗口尺寸以及离开路由后的滚动恢复。截图位于 `_tmp/writer-polish/`。写作运行时 16 项、原有浏览器功能 16 组、双人协作 10 类与阅读预览回归通过；模拟验证不修改真实作品。

### 版本确认与历史预览

版本冲突窗口不再直接显示正文 JSON。`WriterVersionPreview` 用只读的视图展示段落、原有换行与缩进、插图、字数和保存时间；词条展示简介、属性及关联关系。两栏独立滚动，窄窗口改为上下排列。历史／本机版本也共用这套预览；格式无效时提供无法预览提示，不展示原始数据。

本机与云端各自提供 JSON 备份导出，保留使用云端和继续编辑本机的处理逻辑。预览过程不重写稿件内容、段落 ID 或保存协议。运行时新增只读预览测试（共 17 项），浏览器回归检查可阅读段落、换行、图片与云端导出内容；页面错误为零。新版截图位于 `_tmp/writer-version-preview/`。

### 分卷目录与拖拽排序

目录将分卷标题之后、下一个分卷之前的内容归入该卷。标题左侧箭头折叠／展开，显示所属篇数，折叠时仍能提示正在编辑的章节；折叠状态按账号及作品记忆。搜索和草稿／已发布筛选自动展开匹配章节，并保留所属分卷标题作为上下文；清除条件后恢复原来的折叠状态。

右侧三个小圆点轻点打开管理菜单，按住并移动后进入排序。移除菜单中的上移／下移；拖动章节可跨卷，拖动分卷会连同其隐藏章节整体移动。落点线、拖动标题、边缘自动滚动、Esc／窗体失焦／放到目录外取消完善长目录操作。键盘可在管理按钮上按 Alt＋空格进入排序，方向键选择位置，Enter 确认，Esc 取消。

排序沿用 `resort_article`，发送完整章节 ID 和连续序号，保留编辑器与稿件会话；保存失败恢复原顺序。搜索／筛选及无排序权限时禁用拖动，保存期间防止重复操作，过期刷新响应不能覆盖新顺序。新建 `npm run test:writer:catalog` 使用模拟服务验证这些行为，截图位于 `_tmp/writer-catalog/`；运行时增加分卷上下文与排序完整性测试（共 19 项）。
